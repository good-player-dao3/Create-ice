## 简介
一个Create Fly的附属mod,加入了一些与冰相关的东西和配方

## 我们加入了
- **工业海绵**——可以装在动态结构上吸水
- **制冰机**——可以大量生产冰块
- **可燃冰**——不仅可以烧，还可以当做蓝冰使用
- **细雪的流体形态**——这下可以用流体储罐存储细雪了
- **梗图**——依旧猎奇
- **冰砖**——十分不错的材料，可以做冰船的赛道
- **掺了料的雪球**——下了药的雪球
- **更强的土豆加农炮**——可以发射雪球和药水
